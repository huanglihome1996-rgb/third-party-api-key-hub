- (decision) Confirmed domain cardinalities: App and external shop are many-to-many through Installation/Authorization; each external shop belongs to one brand; brand and internal shop are bidirectionally one-to-one.
- (decision) Confirmed runtime shape: Go project with a Linux resident service for third-party callbacks and a CLI for retrieving directly usable API credential information; both share the core domain and adapters.
- (decision) Confirmed deployment direction: provide reproducible build and packaging commands for Linux targets, support systemd for the resident service, and avoid binding the project to one package format.
- (decision) Confirmed CLI preference: JSON-first stable machine-readable output suitable for AI and scripts, with future independent distribution to user terminals.
- (assumption) TikTok is an example rather than a finalized provider/product line; exact TikTok product, authorization method, secret backend, and complete-token output policy remain open.
- (change) Applied structural and prose polish: front-loaded the outcome, moved users and decisions before solution detail, separated confirmed constraints from open decisions, and normalized Chinese terminology.
