平台协议仍为 A-2／Q-7：目标市场／App 类型、回调、有效期／轮换、验证及失效分类尚需核实。官方资料仅作线索，不能宣称联调完成；平台撤销 API 未核实不阻塞本地停用。

R-9 批准按角色交接。架构负责存储、Linux、权限、审计、调度／重试／并发／缓存与必要质量目标；CLI 负责字段、命令、输入、错误编码；接入负责平台核实。均在对应 Story 编写前落实，未落实不可视为可实施。Vaultwarden 同步细节在后续集成启动前落实，不作为首期阻塞，不推定替换生产密钥后端或扩大首期取密权限。

规则章节和 NFR-2／FR-12 的陈旧措辞已由主任务改为技术交接表达；查询触发即时刷新明确交架构／接入设计在生命周期 Story 前落实，不预设策略。当前未发现遗漏或实质决定矛盾。
