# 结构与文字审校

本文档帮助项目负责人、架构设计者和开发者理解首期需求及技术交接。依据 bmad-review 的 structure、prose 两项审校，先处理结构，再检查文字；内容与用户决定保持不变。

## 结构检查

采用 Strategic/Context Pyramid。word_metrics.py 的实际计数为：整理前 PRD 15,249 字词，addendum 2,851 字词，合计 18,100；无指定长度目标。

| Pass | Original Text | Revised Text | Changes |
| --- | --- | --- | --- |
| structure | PRD 首期与后续边界，349 字词，原位于 FR 之后 | MOVE 到产品目标之后 | 先展示范围，再阅读需求；净减量 0。已采用。 |
| structure | PRD 查询与生命周期规则，1,974 字词 | CONDENSE 为边界速查，保留 FR 引用 | 删除重复长交接说明，独有的权限信息与查询触发刷新交接分别进入 FR-11、Q-6。预计减 1,274。已采用。 |
| structure | PRD CLI 输入与输出契约，375 字词 | MERGE 已有规则到所属 FR，保留短速查 | 导入结果不回传凭据值写入 FR-6。预计减 275。已采用。 |
| structure | PRD 成功判据基线，2,317 字词，SM-4／SM-5 长段 | CONDENSE 为按情形分组的验收清单 | 保留 SM-1 至 SM-8、SM-C1／C2，减少复述并拆分正反例。预计减 767。已采用。 |

以上预计总减量 3,346 字词（18.5%）。定稿实际计数为 PRD 12,430 字词、addendum 2,065 字词，合计 14,495；较整理前减少 3,605 字词（19.9%）。主要取舍为减少重复全文、增加明确交叉引用，保留速查和验收情形。
